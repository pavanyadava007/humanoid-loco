## Verdict: not feasible on this host

- Blocker: free disk 5.0 GB, below the 30 GB threshold this check assumes for Isaac Sim + Isaac Lab + shader/extension caches (assumption, not measured); the brief also caps Isaac downloads at 2 GB

- Note: Isaac Sim 4.x wheels are tagged manylinux_2_34 (cp310), so glibc 2.34 alone does not block pip install of 4.x; 5.x/6.x wheels need glibc 2.35. The Isaac Sim documentation lists Ubuntu and Windows as supported OSes; Amazon Linux 2023 is not listed: runtime compatibility on this OS was not tested.
- Note: Only the isaacsim and isaacsim-kernel wheel sizes were measured (HEAD). A full Isaac Sim pip install pulls many more isaacsim-* packages plus extension caches; their total size was not measured here.

Consequence for this repo: no Isaac Lab training or evaluation was run. All results come from MuJoCo Playground (MJX) training and plain CPU MuJoCo evaluation.
